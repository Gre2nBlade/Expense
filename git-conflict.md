# Описание созданного конфликта в проекте

При попытке слияния ветки `docs/project-notes` в ветку `main` возник конфликт в файле `project-notes.md`. 

## Конфликтный участок кода:
```text
<<<<<<< HEAD
- База данных: **SQLite** (файл **expense.db**)
=======
- База данных: **SQLite**
>>>>>>> docs/project-notes
```

## Разбор и описание конфликта:
1. **Откуда конфликт:** Две ветки одновременно попытались перезаписать одну и ту же первую строку файла `project-notes.md`. Git не смог автоматически решить, какое изменение важнее.
2. **Версия HEAD (наша текущая ветка `main`):** В ней строка содержит текст: *"- База данных: **SQLite** (файл **expense.db**)"*
3. **Версия docs/project-notes (вливаемая ветка):** В ней та же строка содержит текст: *"- База данных: **SQLite**"*

## Как был разрешен конфликт:

Было принято решение оставить вариант из ветки main.
