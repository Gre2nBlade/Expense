# Project Notes — Expense

Заметки по разработке проекта «Expense» (учёт личных расходов).

## Цель проекта

Создать простое и понятное приложение для учёта доходов и расходов обычного человека.  
Основной упор — на удобство, чистый код и понятное API.

Налоговый расчёт — **опциональная** функция. Её можно включить или выключить в настройках.

## Основные сущности

- **Transaction** — операция (доход / расход)
- **Category** — категория расходов или доходов
- **Settings** — настройки приложения (в т.ч. вкл./выкл. налогов)

## Что уже продумано

1. Транзакции имеют тип: `income` или `expense`.
2. Категории создаются пользователем.
3. Налоги:
   - по умолчанию **выключены**;
   - если включить — можно указать ставку (например, 13%);
   - расчёт идёт только по доходам за выбранный период.
4. Отчёты: сумма по категориям, общий баланс, (при включённых налогах) сумма налога.

## Стек

- Backend: **Python + FastAPI**
- База данных: **SQLite**
- Frontend: **чистый HTML + CSS + JS**

## Идеи на будущее

- Экспорт в CSV
- Простые графики (Chart.js)
- Тёмная тема
- Регулярные платежи / напоминания
- Несколько пользователей

## Технические решения

- Все даты хранить в формате `YYYY-MM-DD`
- Суммы — `float` / `Decimal` с двумя знаками
- Валидация через Pydantic

## Риски и ограничения

- Налоговый расчёт очень упрощённый (только процент от дохода)
- Нет авторизации (один пользователь)
